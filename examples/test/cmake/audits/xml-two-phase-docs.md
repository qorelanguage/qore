Scope: cmake/QoreMacros.cmake, the new examples/test/cmake/test_two_phase_docs.py,
module-structure design guidance and the corresponding release-note paragraph.
The full audit-changes skill and its module structure, sandboxing, cancellation
and provider guides were reviewed. No astparser, native or user-module changes.

The XML documentation audit reproduced a configure failure on CMake 3.18.4:
file(COPY_FILE) was introduced in 3.21, while the consuming project supports 3.18.
configure_file(COPYONLY) preserves the input bytes and works at the existing floor.
References: [CMake file](https://cmake.org/cmake/help/latest/command/file.html#copy-file),
[CMake 3.14 configure_file](https://cmake.org/cmake/help/v3.14/command/configure_file.html).

/tmp/wsdl-docs-review/build-debug; no installed files are changed. Tests enable
Doxygen commands only as build markers to isolate the exported helper; actual
Qdx/Doxygen XML integration is validated separately. No C++ change or Valgrind
requirement for this commit.
