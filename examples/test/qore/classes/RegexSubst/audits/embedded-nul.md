# Regex substitution embedded-NUL audit

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: include/qore/intern/QoreRegexSubst.h, lib/QoreRegexSubst.cpp,
examples/test/qore/classes/RegexSubst/embedded-nul.qtest, the regex language/release
pages, and design/unicode-case-mapping.md. The full audit-changes skill and its
module-structure, sandboxing, cancellation and DataProvider guides were reviewed.
No astparser changes, installation or push. The user authorized a scoped develop
commit while other core development continues.

The XML integer test exposed loss of the suffix after an embedded NUL in an
unmatched regex substitution. PCRE2 receives the full subject, but Qore copied
its tail using a C-string append. Runtime pattern compilation, replacement
scanning, case-converted captures and callback result copying had related
zero-termination assumptions. The fix passes lengths at each of those boundaries.

Validation against the final native source:

- Existing build-debug is Debug with /usr prefix, matching /usr/bin/qore.
  `cmake --build build-debug --target libqore -j4` succeeds without compiler
  warnings. The first build rejected an invalid concat overload; the final
  build uses explicit byte-pointer/length calls. Logs retain both attempts.
- `LD_LIBRARY_PATH=build-debug build-debug/qore --enable-debug` runs the six
  new cases with 89 assertions in both PCRE2 modes. The six cases all failed
  against the parent before the fix.
- Seven affected suites pass 81 cases / 818 assertions with production JIT:
  Regex, RegexExtract, RegexSubst, embedded-nul, RegexMatchIterator,
  regex_extract and operators/regex. The six class/function suites also pass
  62 cases / 451 assertions with QORE_PCRE2_NO_JIT=1.
- The additionally attempted full operator interpreter run times out after
  240 seconds. A verbose 30-second reproduction locates it at the first 5.5 MB
  no-match scan, after all assertions for the 4.9 MB subject passed. The
  existing test documents PCRE2's REQ_CU_MAX * 1000 optimization cutoff;
  pcre2_match.c confirms that its interpreter omits the required-code-unit
  scan above that bound. This is independent of substitution copying and is
  retained as a P9 environment finding, not a passing run. Production JIT
  was already the supported performance path in the committed JIT-control
  audit. No test filter, skip or enlarged deadline was introduced.
- `QORE_PCRE2_NO_JIT=1 LD_LIBRARY_PATH=build-debug valgrind --leak-check=full
  --show-leak-kinds=all --errors-for-leak-kinds=definite,indirect,possible
  --error-exitcode=97 build-debug/qore -b --enable-debug
  examples/test/qore/classes/RegexSubst/embedded-nul.qtest` passes 6/89:
  zero errors and zero definite/indirect/possible loss, no suppressions.
  The previously isolated DW_AT_abstract_origin reader warning remains
  recorded under XML P9; it is not counted as a clean tool-warning result.
- Downstream XML: 35 affected suites pass 463 cases, including 16 integer
  lexical cases / 983 assertions and full request/response consumers.
  The independent integer matrix validates 936 documents and exact values.

Logs: /tmp/wsdl-p3-core-nul-{before,after,build-final,valgrind}.log,
/tmp/wsdl-p3-core-{jit,interpreter}-*.log, and
/tmp/wsdl-p3-core-interpreter-regex-location.log. Template/release documentation
was regenerated by the native build; the example is also exercised by the
byte-preservation regressions.
